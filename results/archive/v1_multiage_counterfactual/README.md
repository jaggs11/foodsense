# Results

**This directory is empty by design until the experiments have actually been run.**

Nothing here is hand-written. Every table and figure is emitted by a script in
`experiments/`, and is committed only after that script ran to completion on real data.
If a number is not in this directory, it does not exist.

```bash
make eval        # regenerate everything (./make.ps1 eval on Windows)
```

See [`docs/evaluation.md`](../docs/evaluation.md) for what each artefact measures.
